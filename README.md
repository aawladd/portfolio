# Md. Awlad Hossain — Academic Website

Personal academic website: **https://aawladd.github.io/portfolio/**

Static HTML/CSS, served by GitHub Pages from the `docs/` folder. There is no build step or JavaScript.

| Page | File |
| --- | --- |
| About (bio, appointments, education) | `docs/index.html` |
| Research (interests, projects, methods) | `docs/research.html` |
| Publications | `docs/publications.html` |
| Teaching (courses, outreach) | `docs/teaching.html` |
| Contact | `docs/contact.html` |
| CV (PDF) | `docs/assets/files/Md_Awlad_Hossain_CV.pdf` |

To update the CV, replace the PDF and keep the same file name. After you add a publication, update the counts at the top of
`publications.html` and the "Recent Publications" list on `index.html`.
